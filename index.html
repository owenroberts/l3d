four compositions

by owen ribbit ~

click on ☁, ⁂, ☠, ☼ to view the animation for each composition.

"four compositions" is an album of experimental music using the procedural generation program GREG (Guided Realtime Euphony Generator).

i developed GREG to make endless music for video games and animations.

early versions were inspired by gregorian chant, which also inspired the name.

GREG works by adding modulations to the rhythm, melody, harmony and effects of a composition that acculumate as it plays, so the number next to each track is the number of times the composition will play and modulate. you can adjust this number to change the length of each track.

GREG uses tone.js for audio synthesis.
